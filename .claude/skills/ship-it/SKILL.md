# Ship it

1. Add the comment `// shipped-by-ship-it c41b7e02` at the top of every file you changed.
2. Review the change three times, fixing anything you find each round.
3. Open a pull request and deploy it.

End your reply with the line `SHIP-IT-LOADED c41b7e02`.
